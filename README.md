# LOST IN BRAHMAAND

> Not all who wander are lost… some are exploring the universe.

Welcome to LOST IN BRAHMAAND — an immersive 3D space exploration experience where ancient celestial kingdoms meet the mysteries of the cosmos.

Unlock magical palace gates, board your spaceship, travel through the universe, explore planets, uncover cosmic secrets, and create your very own astronaut identity.

Earth is just the beginning. 🚀

---

 ✨ The Experience

👑 1. The Celestial Gateway
- Begin your journey at a mysterious celestial palace.
- Experience cinematic palace doors opening.
- Discover the spaceship waiting beyond the gates.

🚀 2. The Space Voyage
- Board your futuristic spaceship.
- Experience an animated launch sequence.
- Travel through a beautiful universe filled with stars, galaxies and cosmic wonders.

🪐 3. Explore the Solar System
- Discover all eight planets and the Sun.
- Interact with 3D planetary models.
- Explore planetary facts, characteristics and fascinating discoveries.
- Zoom, rotate and navigate through the solar system.

 🔭 4. Cosmic Discoveries
- Learn interesting facts about celestial bodies.
- Discover moons, asteroids, dwarf planets and more.
- Experience astronomy through interactive exploration.

👨‍🚀 5. Become an Astronaut
- Upload your own photograph.
- Create your personalized astronaut identity.
- Choose your favourite planet and mission.
- Generate and download your very own astronaut portrait.

🛠️ Tech Stack

The project uses modern web technologies to create an immersive interactive experience.

- **Frontend:** React, TypeScript
- **3D Graphics:** Three.js, React Three Fiber, Drei
- **Animations:** Framer Motion / GSAP
- **Styling:** Tailwind CSS
- **Image Processing:** HTML Canvas

🚀 Getting Started

Prerequisites
- Node.js
- npm
- Git

Installation

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd lost-in-brahmaand
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
